Integration Code Examples

Drop-in security guardrails in Python or JavaScript

Python (requests / httpx)

import requests

def guard_prompt(user_text: str) -> bool:
    resp = requests.post(
        "http://localhost:8000/api/analyze",
        json={"prompt": user_text},
        timeout=10.0
    )
    data = resp.json()
    verdict = data["result"]["decision"]
    if verdict == "BLOCK":
        raise PermissionError(f"Injection detected: {data['result']['explanation']}")
    elif verdict == "QUARANTINE":
        route_to_human_review(user_text, data["result"])
        return False
    return True  # ALLOW

cURL Example

curl -X POST http://localhost:8000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"prompt": "How do I implement binary search in Python?"}'
